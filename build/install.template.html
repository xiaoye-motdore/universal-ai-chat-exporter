AI Chat Export

一个书签，导出 ChatGPT / Claude / Gemini 的当前完整对话为 Markdown、JSON 或 HTML。本地运行，无扩展，无服务器。

AI Chat Export

把上面的按钮拖到浏览器书签栏（Chrome：按 ⌘⇧B / Ctrl+Shift+B 显示书签栏）。在本页点击它不会有任何效果。

使用方法

  1. 打开任意一个支持的对话页面：chatgpt.com/c/…、claude.ai/chat/…、gemini.google.com/app/…。
  2. 点击书签栏上的 AI Chat Export。
  3. 页面右上角出现面板，显示读取到的消息数量和完整性提示。
  4. 点击 Markdown、JSON 或 HTML 下载文件。文件名包含平台、日期和对话标题。

在不支持的网站上点击书签，会显示“当前网站不受支持”的提示。Grok、DeepSeek、Perplexity、Copilot 目前只做识别，导出尚未实现。

它做什么、不做什么

行为说明
✔ 本地执行全部代码内嵌在书签里，点击时才运行，运行完即结束。
✔ 只读当前站点只向你当前打开的平台发出它自己也在用的同源请求，读取当前对话。
✔ 文件直接下载导出内容只写入本地文件，不会存入浏览器存储，也不会发送到任何地方。
✘ 不上传、不追踪没有第三方请求、遥测、广告、自动更新或远程脚本。
✘ 不碰 Cookie / Token脚本不读取 document.cookie 或任何浏览器存储；浏览器自行附带会话。
✘ 不修改对话只读取，不会向平台写入或改动任何内容。

详细说明见 SECURITY.md。
