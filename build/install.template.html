AI Chat Export

一个书签，把 ChatGPT、Claude、Gemini、Grok、Perplexity 的当前对话完整导出为 Markdown、JSON 或 HTML。本地运行，无扩展，无服务器。

📤 AI Chat Export ↑ 把这个按钮拖到书签栏

Chrome 按 ⌘⇧B / Ctrl+Shift+B 显示书签栏。在本页点击按钮没有效果，请拖拽。

✓ChatGPT ✓Claude ✓Gemini ✓Grok ✓Perplexity ◐Copilot 实验 ○DeepSeek 计划中

三步导出

1

打开任意一条支持平台的对话页面。

2

点击书签栏上的 📤 AI Chat Export，右上角出现面板。

3

看一眼消息数和完整性提示，点 Markdown / JSON / HTML 下载。

它做什么，不做什么

  • ✓全部代码内嵌在书签里，点击时才运行
  • ✓只向当前平台发它自己也在用的同源请求
  • ✓导出内容直接写入本地文件
  • ✓保留分支、附件元数据、代码、表格、公式
  • ✘不上传、不遥测、不加载远程脚本
  • ✘不读 Cookie，不碰浏览器存储
  • ✘不修改任何聊天内容
  • ✘不跨网站读取，只看当前打开的对话

详细说明见项目里的 SECURITY.md。
